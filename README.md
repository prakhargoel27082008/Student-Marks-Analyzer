# 📊 Student Marks Analyzer

A Python-based Student Marks Analyzer that calculates grades, ranks students, generates visualizations, and exports results using Pandas and Matplotlib.

## 🚀 Features

- Read student data from a CSV file
- Calculate Total Marks, Average, and Percentage
- Assign Grades (A+, A, B, C, D, F)
- Determine Pass/Fail status
- Find the Topper and Lowest Scorer
- Rank students based on total marks
- Search for a student by name
- Visualize total marks using a bar chart
- Export the final results to a CSV file

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- VS Code
- Git & GitHub

   ```

   ```
   python main.py
